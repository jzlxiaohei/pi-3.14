# PIE Workspace

PIE organizes durable code-agent work while leaving PI responsible for the conversation sessions it creates and maintains.

## Language

**Task**:
A durable unit of work owned by PIE. Each Task corresponds to exactly one PI Session and has its own lifecycle and application metadata.
_Avoid_: Chat, job, session

**Root Task**:
A Task created directly by the user rather than generated by another Task. Only Root Tasks appear in the main task sidebar.
_Avoid_: Top-level session

**Active Task**:
The Task whose PI Session is currently open. It may be a Root Task or Child Task; the sidebar selection is its Root Task ancestor.
_Avoid_: Selected Session

**Child Task**:
A Task generated by a parent Task through a Subagent. It remains independently inspectable and resumable despite being hidden from the main task sidebar.
_Avoid_: Background job, tool call

**Task Tree**:
The generation lineage formed by Root Tasks and Child Tasks. Every Child Task has exactly one parent, so generation lineage is a tree rather than a dependency graph.
_Avoid_: Dependency graph, workflow graph

**Subagent**:
An agent delegated work by another Task and given an independent PI Session. Persisted Subagent work is represented by a Child Task.
_Avoid_: Child process, background thread

**PI Session**:
The PI-managed conversation and execution history that is the source of truth for messages, tool calls, branches, and summaries. PIE references it but does not treat application metadata as part of it.
_Avoid_: Task, transcript copy

**Session Availability**:
Whether the PI Session belonging to a Task can currently be found and opened. Availability is separate from Task Status.
_Avoid_: Task status

**Task Status**:
The latest execution condition of a Task: idle, running, done, error, or interrupted. Interrupted means execution ended without a recorded normal completion or explicit error.
_Avoid_: Session availability

**Archive**:
A reversible PIE state that hides a Task Tree from the default workspace without deleting its PI Sessions.
_Avoid_: Delete, purge

**Preference**:
PIE-owned user interface state expected to survive application restarts, scoped globally, to a workspace, or to a Task.
_Avoid_: PI setting
