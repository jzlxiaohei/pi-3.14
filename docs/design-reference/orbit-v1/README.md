# Orbit v1 Design Reference

`demo.html` is a cleaned, static snapshot of the first Orbit code-agent UI prototype.

It is visual reference only:

- Do not import it from app code.
- Do not copy its inline SVGs or React-generated markup into production UI.
- Use `apps/desktop/src/renderer/src/styles/tokens.css` for runtime styles.
- Use `.agents/skills/build-orbit-ui/assets/tokens.css` as the canonical token source.
